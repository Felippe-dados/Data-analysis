# Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes sales data to evaluate revenue performance by product and region.  
The objective is to identify key revenue drivers and understand business distribution patterns.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Business Performance Analysis

## 📊 Analysis Performed
- Revenue by product category
- Sales volume comparison
- Regional revenue distribution
- Identification of top-performing products

## 📈 Key Insights
- Notebooks represent more than 50% of total revenue, being the main revenue driver.
- Monitors and printers contribute significantly to overall revenue.
- Mouse and headset show high sales volume but lower financial impact.
- Revenue distribution across regions is balanced, with the Northeast slightly leading.

## 📷 Dashboard Structure
The dashboard was built using Pivot Tables and visual indicators to allow fast and strategic decision-making.

## 🚀 Conclusion
The business shows strong dependence on high-value products and maintains balanced geographic distribution, reducing regional risk concentration.

# 📌 Versão em Português

## 📊 Visão Geral do Projeto
Este projeto realiza uma análise de dados de vendas com o objetivo de avaliar o desempenho do faturamento por produto e por região.  
O foco é identificar os principais geradores de receita e compreender o comportamento da distribuição comercial.

## 🛠 Ferramentas Utilizadas
- Microsoft Excel
- Tabelas Dinâmicas
- Análise de desempenho comercial

## 📈 Análises Realizadas
- Faturamento por categoria de produto
- Comparação de volume de vendas
- Distribuição regional de receita
- Identificação dos produtos com maior impacto financeiro

## 🔎 Principais Insights
- Notebooks representam mais de 50% do faturamento total, sendo o principal gerador de receita.
- Monitores e impressoras possuem participação relevante no faturamento.
- Mouse e headset apresentam alto volume de vendas, mas menor impacto financeiro.
- A distribuição regional é equilibrada, com leve destaque para o Nordeste.

## 🏁 Conclusão
A análise demonstra dependência estratégica de produtos de maior valor e uma distribuição geográfica equilibrada, reduzindo riscos de concentração regional.
